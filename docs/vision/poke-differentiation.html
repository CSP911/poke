POKE 차별점

로봇을 LLM으로 학습시키는 시도는 2026년 현재 세 갈래로 몰려 있다. 모두 더 똑똑한 뇌를 만드는 경쟁이다. POKE는 그 아래, 뇌가 내린 코드를 몸이 받아 실행하는 층을 바꾼다. 이 메모는 지금 기준으로 무엇이 같고 무엇이 다른지 적는다.

다른 곳은 더 똑똑한 뇌를 만든다. POKE는 어떤 뇌든 꽂을 수 있고, 몸이 바뀌어도 되고, 뇌가 실수해도 안전하고, 스스로 기억하고, 자기 하드웨어를 스스로 배우는 몸을 만든다.

1. 지금 로봇 학습의 세 갈래

갈래방식대표 (2026)필요한 것

2. 솔직한 자리매김

같은 것POKE 코치의 "LLM이 움직임 구조를 쓰고 → 숫자를 시행착오로 다듬는" 고리는 B 갈래(Language to Rewards, Eureka)와 구조가 같다. 2023년에 나온 방식을 다른 자리에서 다시 쓴 것이다. "우리가 먼저"라고 주장하면 안 된다.
지는 싸움움직임의 품질로 겨루면 진다. 시뮬레이션에서 LLM이 쓴 걸음은 손으로 쓴 단순 파동보다 2~3배 느렸다. VLA의 손재주를 LLM이 쓴 C 코드가 따라갈 수 없다.

그래서 POKE는 뇌의 자리에 서지 않는다. 뇌가 무엇이든, 그 뇌가 내놓은 것이 어디서 어떻게 실행되는가를 바꾼다.

뇌 (남들의 경쟁)
VLA 정책, LLM이 쓴 코드, 학습된 작은 신경망. POKE에서는 이 모두가 "기술(skill)"이라는 한 종류의 입력이다.
POKE
기술을 격리된 프로세스로 실행하고, 커널이 안전 규칙을 강제하고, 몸을 스스로 발견하고, 배운 것을 기기 자신의 저장소에 기억하고, 처음 보는 하드웨어의 드라이버를 AI가 쓰게 하는 층.
몸
모터, 센서, 보드. 어떤 조합이든 알파벳처럼 다시 조립된다.

아래는 2026년 10월 현재 동작이 확인된 것만 적었다. 실기기는 Pi 4에서, 트윈은 QEMU 위의 가상 POKE(같은 커널)에서 검증.

4. 시뮬레이션으로 이미 해 본 것

"생성되는 몸"의 전 과정은 실제 서보가 오기 전에 시뮬레이션에서 먼저 돌렸다. 두 층의 시뮬레이션을 썼다: 몸은 MuJoCo, POKE 자체는 QEMU 트윈(실기기와 같은 커널 바이너리를 가상 Pi 4에서).

  • 10-01
    첫 고리 — 서보 모듈 사슬(MuJoCo). 자기 발견 → LLM 기술 생성 → 병렬 시뮬 48×6으로 숫자 다듬기 → 3라운드 피드백 → 모듈 제거 → 재생성. 4관절 3.5 cm/10 s, 모듈 하나 뽑은 뒤 3관절 4.8 cm/10 s. 안전 개입 ≤ 0.5 %.
  • 10-02
    음성 코치, 손가락 — 세운 관절 3개 = 검지. 가상 관찰자 또는 사람이 보며 말함("움직였어", "반대야", "쥐었어"). 기술은 맥이 아니라 가상 POKE(트윈) 안에서 EL0 프로세스로 실행, 커널 안전 필터를 거침. 맥과 POKE의 결과가 1e-7 이내로 일치.
  • 10-05
    기억 — 코치가 기기 스토어의 기술을 참고로 받아 시작하고, "그거야"에 기술+숫자+이미지를 기기 SD에 저장. 재부팅 후 스토어에서 꺼내 다시 스텝. 실기기에서는 전원 재부팅 후 6개 레코드 잔존 확인.
  • 10-06
    AI 인큐베이팅 — QEMU에 가상 I2C 장치 4개를 꽂고 모델에게 버스 서비스만 줌. 23번 접근으로 3개 식별, 드라이버 3개 작성·주입·자가 검증 통과.

시뮬레이션이 준 것은 속도만이 아니다. 실기기로 옮길 때 바뀐 것은 주소 하나(SD 컨트롤러)뿐이었고, 그 사실 자체가 "기판이 같다"는 증거다.

5. 가야 할 길

뇌 경쟁에서 빠진다기술 = LLM이 쓴 코드 또는 학습된 작은 신경망을 C로 컴파일한 것. 남들의 뇌 발전이 전부 POKE의 발전이 된다.
남들이 못 찍는 장면다리 하나를 뽑으니 3초 뒤 다시 걷는다. 말로 코치하니 배우고 기억한다. 처음 보는 센서를 꽂으니 AI가 드라이버를 쓴다. 생성 코드가 폭주해도 기기는 멀쩡하다.
정직한 문장"Language to Rewards 계열의 생성-조정 고리를, 베어메탈 격리 실행 + 커널 안전 + 사람 음성 보상 + 기기 내 기억 + 가변 형태 위에서 돌린다."

아직 없는 것

  • 실제 서보 몸(부품 대기). 시뮬-실기기 차이는 아직 측정 전.
  • 지각(카메라). 지금의 "눈"은 사람이다.
  • 학습된 신경망 정책을 기술로 받아들이는 경로(설계만 있음).
  • SMP·다중 레지던트(프로세스 테이블 6단계).
