# I2C 0x49 — TMP102/TMP112-compatible I2C digital temperature sensor
**Status: verified.** The resident `i2c-temp-49` was written from this identification and its readings
matched ground truth on the twin (2026-10-06 00:21).

**Evidence:** Pointer 0x00 (temp) = 0x1B80 -> (0x1B80>>4)*0.0625 = 27.5°C, a sane reading in the 12-bit left-justified TMP10x format. Decisive extra check beyond the earlier note: pointer 0x02 (TLOW)=0x4B00 -> 75.0°C and pointer 0x03 (THIGH)=0x5000 -> 80.0°C, which are exactly the documented TMP102 power-on default alarm thresholds (75°C/80°C). TMP101 and other look-alikes at this address family lack these TLOW/THIGH registers, so finding them populated with the documented default values confirms the TMP102/TMP112 register map specifically rather than just 'some temp sensor'.

**Reading:** Read 2 bytes from pointer 0x00; value = (raw>>4) * 0.0625 °C (raw is signed 12-bit, left-justified in a 16-bit big-endian word).
